# Python Fundamentals

This repository contains a collection of Python programming exercises designed to build a solid foundation in core programming concepts. It covers fundamental topics such as variable manipulation, data structures (lists, dictionaries, etc.), control flow, and basic functions. The project serves as a practical portfolio of introductory Python skills, demonstrating the ability to write clean, executable code to solve logical problems.

## How to Run the Exercises

To run these exercises on your local machine, ensure you have Python installed (version 3.x is recommended).

What I Learned

1.Syntax and Structure: Gained a strong understanding of Python's basic syntax, indentation rules, and variable scoping.

2.Data Structures: Learned how to effectively utilize built-in data types like lists and dictionaries to store and manipulate information.

3.Control Flow: Developed the ability to write conditional logic (if/else) and loops (for/while) to control the execution path of a program.

4.Problem Solving: Improved logical thinking and debugging skills by translating abstract problems into functional Python code.
